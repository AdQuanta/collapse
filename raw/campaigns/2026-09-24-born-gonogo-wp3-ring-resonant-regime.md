## P0 [PROVED] — tiers Tier 1; the z-field slices of Tiers 3-5 (translation-invariant, Pi-symmetric rings)

**Statement.** The outcome-0 pencil has at least D(N) = sum over irreps rho of the dihedral group D_N of |m_+(rho) - m_-(rho)| dim(rho) roots exactly at lambda = 0 (the north pole). Here m_pm(rho) is the multiplicity of rho in the detector-parity sectors prod_i Z_i = pm 1. D(N)/2^N = 0.375, 0.188, 0.102, 0.055, 0.028, 0.014 for N = 4, 6, ..., 14, so this finite-size vacuous north atom vanishes roughly like 2^{-N/2}.

**Hypotheses.** Pi = Z_0 prod Z_i commutes with H (h0x = h0y = hx = hy = 0); the ring is uniform (dihedral symmetry); U11 is invertible (regular pencil).

**Proof / argument.** Pi conservation means U10 flips the detector parity and U11 preserves it. The dihedral group acts on the detector only and commutes with H and with prod Z_i, hence with K = U11^{-1} U10. On the multiplicity space of each irrep, K is block off-diagonal between the parity blocks, so its rank is at most 2 min(m_+, m_-), which gives |m_+ - m_-| zero eigenvalues, each repeated dim(rho) times. A zero eigenvalue of K is a root lambda = 0. Earlier guess ruled out: dark states in H_D eigenspaces (E cap ker L_x) give only 1, 1, 0, 0 for N = 4, 6, 8, 10, so they are not the mechanism.

**Numerical evidence.** v3_parity_atoms.py: dihedral count 6/12/26/56/116/236 for N = 4..14; the translation-only count (4/8/16/...) is insufficient. The bound is attained exactly in every Tier-1 run: 12/64 at N = 6, 26/256 at N = 8, 56/1024 at N = 10, for all h0z, g, T. Consequence: N = 4 is dominated by the atom (37.5 %) and is never used for trends. The x-statistics below exclude these atoms (theta < 1e-8).

## P1 [PROVED] — tiers Tiers 1-5 on every resonance (Tier 1 on R1; Tier 2 in the h0-hat frame; Tier 4 XXZ)

**Statement.** Graded-RWA theorem. Let H = h (n.sigma_0) + H_D + V, with h != 0, any detector H_D and any coupling V. (b) If [H_D, M] = 0 and only the co-rotating coupling sigma_0^+ A_- + sigma_0^- A_+ is kept (plus charge-neutral terms), then [H, Z_0 + M] = 0 and the same holds in the z basis. For Tier 1, (b) is (g/2)(X0 sum X + Y0 sum Y)/sqrtN, the charge-graded slice g_x = g_y = g/2. On R1, all of the rotating-wave exchange is therefore degenerate: every nontrivial root structure comes from grading-breaking terms (counter-rotating, longitudinal, off-shell).

## P2 [PROVED] — tiers Tier 1; Tier 3 with z-only fields; Tier 4 XXZ (any detector with [H_D, M] = 0)

**Statement.** Exact counter-rotating gauge identity, valid at all orders in g and for every N and T. Write the coupling as H(u; v_+, v_-) = h0z Z0 + H_D + u(s0+ A- + s0- A+) + v_+ s0+ A+ + v_- s0- A-, so that u = g_x + g_y and v_pm = g_x - g_y (Tier 1: u = v = g). Then, as root multisets, lambda(u; v_+, v_-) = e^{2s} lambda(u; v_+ e^{4s}, v_- e^{-4s}) for every complex s. Corollary: with kappa = (g_x - g_y)/(g_x + g_y), lambda(kappa) = sqrt(kappa) lambda(u; kappa^2 u, u). Radii are therefore homogeneous of degree 1/2 in the counter-rotating amplitude, up to a relative O(kappa^2) correction. The non-normal amplification of grading breaking is exactly the imaginary-gauge square root, not the Jordan-type eps^{1/s} with s ~ N. Theorem I's sqrt|g_x^2 - g_y^2| law (research_reports/BORN_RESONANT_RETURN.md:29-65) is the leading term.
