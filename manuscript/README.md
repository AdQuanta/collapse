# PRL package

This directory contains a self-contained PRL-style Letter and a separate
single-column Supplemental Material package built from the supplied research
map and the repository's eligible post-July 1, 2026 evidence.

## Primary sources

- `main.tex`: double-column REVTeX Letter with four main-text figures.
- `supplement.tex`: separate single-column REVTeX supplement.
- `references.bib`: shared bibliography.
- `scripts/build_figures.py`: deterministic figure and manifest builder.
- `NUMERICAL_PROVENANCE.md`: run-level provenance and hashes.
- `RESULTS_NEEDED.md`: prioritized missing results.
- `EVIDENCE_REGISTRY.md`, `NARRATIVE_REGISTRY.md`, and `AUDIT.md`: claim and
  review trail.

The compiled submission PDFs and exact build commands are listed in `BUILD.md`.
