# Figure 1: The Collapsible State Framework

**Claim**: Unitary evolution of a qubit-detector system defines a discrete set of "collapsible states" that evolve into perfect product states.

**One-sentence takeaway**: The projective roots of the relative propagator $W=A^{-1}C$ provide a constructive map from the detector's spectral properties to a point process on the Bloch sphere.

**Question answered**: How do we identify the specific initial qubit states that "collapse" under unitary dynamics?

**Panel flow**:
1. **System Schematic**: Qubit $|\phi_0\rangle$ coupled to a many-body detector $H_D$ via $V$.
2. **Mathematical Engine**: The $U(t)$ block partition $\to$ The projective pencil $(C, A) \to$ Eigenvalues $\lambda$.
3. **Geometric Projection**: A set of points $\lambda_i$ projected onto the Bloch sphere as $\theta_i = 2 \arctan |\lambda_i|$.

**Dominant panel**: The geometric projection (mapping the algebraic roots to the physical sphere).

**Instant comparison**: Contrast a "generic" root (random point) with a "collapsible" root (a point that specifically disentangles).

**Quantitative anchor**: The dimension $d$ of the detector defines the exact number of roots.

**Alternative explanation addressed**: This is not a "fuzzy" decoherence result; it is an exact algebraic condition for perfect disentanglement.

**Why main text**: This defines the fundamental object of the paper; without this, the subsequent statistics have no physical meaning.
