# Hossenfelder & Palmer 2020 — Rethinking Superdeterminism

**Reference**: S. Hossenfelder and T. Palmer, *Frontiers in Physics* **11**, 139 (2020).

## Core Thesis
Superdeterminism is a viable path to resolving the measurement problem and apparent nonlocality. By rejecting the assumption of **Statistical Independence** (the idea that measurement settings are uncorrelated with the particles being measured), one can describe the "collapse" as a deterministic, local process emerging from an underlying non-linear system.

## Key Concepts
- **Violation of Statistical Independence**: Posits that hidden variables $\lambda$ are correlated with detector settings. This removes the "spooky action at a distance" by explaining the correlations as a result of common-cause determinism.
- **$\Psi$-Epistemic View**: The wave function is viewed not as a real physical object (ontic) but as a statistical representation of the underlying deterministic theory.
- **The "Conspiracy" Counter-argument**: Argues that "fine-tuning" is a subjective notion based on Euclidean distances in state-space; a different metric (e.g., $p$-adic) could make superdeterministic correlations natural.
- **Invariant Set Theory (IST)**: A proposed framework where the laws of physics emerge from the geometry of a fractal set of allowed trajectories in state-space.

## Relevance to `unitary-collapse`
The `unitary-collapse` project is an exploration of **unitary superdeterminism**. 

While Hossenfelder and Palmer propose non-linear theories (like IST) to explain the "collapse," the `unitary-collapse` program asks: *Can this be done within a purely linear, unitary framework?*

If we identify "collapsible states" as the only states that can physically exist in a measurement context (a form of "state-space restriction" akin to Palmer's RaQM), then the apparent "collapse" is simply the system following a deterministic unitary path from a restricted set of initial conditions. This provides a a rigorous, unitary implementation of the "deterministic outcome" goal of superdeterminism without needing to leave the Hilbert space.
